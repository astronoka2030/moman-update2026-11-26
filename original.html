一、新規追加兵書陣形システム

【兵書策略】

1. 兵書は「孫武兵勢」、「墨守非攻」、「鬼谷奇変」の3大策略に分かれており、それぞれ攻撃、生存、特殊効果に重点を置いています。

2. 各陣営では1種類の策略のみ有効にでき、策略の「研究効果」と「スキル」だけが有効になります。

3. 各策略は兵書の育成進捗を共有しており、策略を切り替えても兵書を再度育成する必要はありません。

【兵書スキル】

1. 兵書には3個のスキルがあり、そのうち1個は兵書の戦闘中スキル、2個は助陣スキルです。

2. 兵書の戦闘中スキルは兵書に対応する策略と関連しており、対応する策略の兵書を選べば、対応する策略の戦闘中スキルを使用できます。

3. 兵書の2個の助陣スキルは、助陣名士の出陣枠と助陣名士のスキル発動を提供し、各策略の助陣スキルは同じです。

【兵書育成】

1. 道具「軍機巻」を使用すると、兵書レベルを上昇できます。

2. 現在の段階レベルが上限に達した後は、「厲兵玉印」を使用して昇階する必要があります。

3. 兵書を昇階すると、攻撃、体力、火力、装甲などの属性を獲得でき、一部の段階では兵書スキルレベルも上昇し、陣形の象嵌枠も解放されます。

【陣形獲得】

1. 「心力丹」を消費して絵陣を行うと、ランダムで一定数の白、緑、または青の陣形を獲得できます。

2. 累計絵陣回数で絵陣レベルを上昇でき、絵陣レベルが上がると、出陣中のすべての陣形の属性を上昇できるだけでなく、1回の絵陣で獲得できる陣形数も増やせます。

【陣形合成】

1. 白色から橙色までの陣形は、同品質の陣形2つを使って合成でき、合成に策略の制限はありません。

2. 合成成功後、ランダムで1つ上の品質の陣形を獲得できます。失敗後は、兵書育成素材を獲得できます。

3. 同品質の合成に失敗すると、以降のその品質の合成成功率が上昇します。その品質の合成に成功すると、成功率は初期値に戻ります。

【陣形星昇級】

1. 白色から橙色までの陣形の星は固定で、星昇級はできません。

2. 赤色の陣形は対応する欠片で星昇級でき、属性バフを上昇させ、所属する策略の陣形総星を増やせます。

3. 各赤色の陣形は1つしか所持できず、重複入手した場合は自動で対応する星昇級欠片に変換されます。

【陣形装着】

1. 各策略には独立した陣形の出陣枠があり、対応する策略の陣形しか装着できません。

2. 陣形を装着すると、その属性バフはすぐに有効になります。策略を有効にしていなくても、すでに装着した陣形の属性バフは得られます。

3. 現在の策略で装着した陣形の総星が指定条件に達すると、その策略の専属スキルレベルを上昇でき、現在の策略のスキル効果のみが有効になります。

二、新たに名士の助陣機能を追加

1. 兵書の「角の陣形」スキルを解放すると、布陣で名士を助陣に配置できます。スキルレベルを上昇すると、より多くの助陣枠を解放できます。

2. 同じ名士は主陣か助陣のどちらかしか選べません。助陣名士は直接出場せず、助陣名士の全属性（名士が携帯する収集品、契約の傑作などを含む）は一定の割合で主陣にバフされます。割合は「角の陣形」スキルのレベルによって決まります。

3. 助陣で出陣している名士が専属収集品を装備している場合、収集品霊韻の装備数にも加算されます。

4. 兵書の「八方の援軍」スキルを解放すると、主陣の名士が行動した後、確率で助陣の名士に号令をかけます。助陣の名士が1回追加で戦闘技を発動し、発動するスキルは助陣名士の各スキルの発動確率によって決まります。「八方の援軍」スキルのレベルが上がると、号令の確率も上昇します。

5. 神話名士が助陣する時、神話スキルは発動しません。

三、金陵決戦新規追加コンテンツ

【参加資格】

1. イベント開始後、参加グループ内の同盟総繁殖度順位に基づき、第1〜27位は逐鹿グループ、第28〜54位は争覇グループに入り、両グループそれぞれで順位報酬を争います。

2. 予告期間終了時に参戦名簿と同盟所属をロックします。ロック後に脱退、移籍、または同盟解散があっても、今期のイベントの参戦所属は変わりません。

3. 各試合には3つの同盟が参加し、それぞれ宋、漢、呉の勢力を代表して、同じ戦場で城地を争奪します。

【イベント日程】

1. 正式な争奪は3日間続き、毎日対戦相手を再マッチングし、勢力を割り当てて戦場を更新します。システムが勢力を割り当てる際は、まず本同盟が今期のイベントで担当した回数が少ない勢力を優先します。

2. 毎日00:00〜09:30、盟主または参謀官が当日の勢力を公布できます。09:30以降は、システムが未公布の勢力を自動で公布します。

3. 毎日10:00〜20:00は版図争奪フェーズです。城地を占城し、優位を積み重ねられます。

4. 毎日20:00〜22:00は中心決戦フェーズです。都城「金陵」と四つの雄関が開放され、埠頭の水路調遣も開始されます。

5. 毎日22:00に争奪が終了し、当日の戦況が集計されます。休戦期間中は戦場に入場できず、部隊派遣もできません。

【昇格と順位】

1. 逐鹿グループ、争覇グループにはそれぞれ豪傑、将相、帝王の3つの章があり、初日はすべての同盟が豪傑章から始まります。

2. 毎日集計時、各勢力が現在占領している城地のポイントに基づいて、その回の順位を決定します。初日の各回で1位の同盟は、翌日に1つ上の章へ昇格し、それ以外の同盟は引き続き元の章で参戦します。

3. 同盟は毎日の試合順位に応じて集計ポイントを獲得し、最終的に3日間の集計ポイント合計で順位を決定します。

4. 個人番付は、本グループのイベント内で獲得した功績に基づいて順位を決定します。

5. 各日の順位に対応する集計ポイントは、「日程」で確認できます。

【城地争奪】

1. 城地は主城、都城、埠頭、雄関、州府、関所、郡県、村鎮の計8種類に分かれます。城地ごとに、占領ポイント、輜重の生産量、バフが異なり、城地詳細で確認できます。

2. 部隊は道路に沿って行軍する必要があります。攻撃、駐屯、または支援で対象の城地に向かう際、部隊の所在地は対象と通行可能なルートでつながっていなければなりません。

3. 行軍中に交戦や敵の妨害に遭うと、部隊は戦闘に入ります。重要な道路を断てば、敵部隊が目的地に順調に到達するのを阻止できます。

4. 城地の戦闘は自動で進行し、部隊の戦闘力は現在の兵力と各種バフで決まります。勝利した部隊は残り兵力でそのまま戦闘を続け、敗北した部隊は主城に戻ります。

5. すべての防衛部隊を撃破すると、攻撃側が城地を占領します。両勢力が共同で攻める場合、最後の防衛部隊を撃破した勢力が城地を獲得し、その後、残りの敵対部隊は引き続き新たな占領側と交戦します。

6. 城地が交戦を停止して5分後、システムキャラの守備隊は上限まで補充されます。

7. 主城は特殊拠点であり、攻撃できるのは駐留守軍のみです。駐留しているプレイヤー部隊は主城の防衛に参加しません。主城の守備隊数は無制限です。

【埠頭と水路】

1. 埠頭は夜間進軍の重要拠点です。毎日20:00〜22:00、主城の部隊を水路で直接自軍占領の埠頭へ調遣でき、途中の陸路の城地を経由する必要はありません。

2. 毎日20:00前、ある埠頭を累計5分占領するごとに、その埠頭の保護時間を1分蓄積できます。

3. 各勢力の各埠頭での占領時間はそれぞれ別に計算されます。20:00時点でなお埠頭を占領している自勢力のみ、その埠頭に蓄積された保護時間を獲得できます。

4. 保護期間中、他勢力はその埠頭を攻撃できません。保護終了後は通常の争奪に戻ります。早めに埠頭を占領して守り抜けば、夜間決戦に向けて安全な進軍ルートを確保できます。

【部隊と徴兵】

1. システムは所持している名士に基づき、自動で槍、弓、盾、騎の4部隊を編成します。

2. 各種実力が最も高い名士が主将を務め、その後の5名が副将を務め、残りの同種名士は後方支援バフを提供し、部隊の兵士上限に影響します。

3. 初めてイベントに入ると、システムが自動で名士データを同期し、部隊に兵士を最大まで配備します。イベント外で名士を上昇した後は、手動で「戦力同期」を行わないと、兵士の上限を変更できません。

4. 兵営はイベント開催期間中、自動で予備兵を募集し、毎日22:00〜翌日10:00の休戦期間中も徴兵されます。予備兵が上限に達すると自動徴兵は停止します。軍令を使うと、すぐに兵士を獲得できます。

5. 待機部隊は予備兵で補充できます。行軍中または交戦中の部隊は補充できません。

6. 玉璧を消費して行軍時間を短縮でき、また自動討伐、軍令の事前保存および玉璧の事前保存を設定し、設定に従って対応する資源を自動で使用できます。

【士気と軍階】

1. 毎日戦場が開放されると、士気は上限まで回復します。部隊が撃破されると全体部隊の士気が低下し、5分間連続で部隊が撃破されなければ、士気を回復できます。

2. 士気が低いほど、出征に必要な最低兵力は高くなります。兵力が不足している場合は、兵士を補充するか、士気が回復するまで待ってから出征してください。

3. 戦闘は撃破数と自軍の損害に応じて功績を集計し、勝敗にかかわらず双方とも実際の戦況に応じて功績を獲得できます。

4. 各勢力には5段階の軍階が設けられています。功績を蓄積し、昇格条件を満たすと、軍階を上昇させ、徴兵速度と行軍速度のバフを獲得できます。

5. 功績と順位が必要な軍階は、30分ごとに自動で評定され、順位の変動に応じて昇格または降格する可能性があります。

【城主と協同】

1. 城地を占領した後、システムはまず自軍の参戦功績が最も高く、かつまだ城主を務めていないプレイヤーを城主に任命します。盟主と参謀官は手動で任免できます。

2. 城主が自分の管轄する城地を防衛する時、10%の戦闘力バフを獲得し、その城地の城池バフを2倍受けられます。

3. 盟主と参謀官は戦略標記を設定し、盟友の攻撃や防衛を指示できます。会員は救援情報から素早く交戦中の城地を特定できます。

4. 「戦略」では、敵の守備、部隊の集結、城地のバフなどの情報を確認でき、進軍ルートの手配に役立ちます。

【目標と収益】

1. 毎日、各勢力に5つの戦略目標城地が更新されます。

2. 当日自軍勢力が目標の城地を占領した場合、対応する報酬を受け取れます。当日終了まで占領を維持する必要はありません。

3. 自軍が占領した城地は継続して輸送を産出し、「勢力」で受け取れます。城地を失っても、それまでの占領期間中に産出された輸送は引き続き受け取れます。

4. 輸送はイベント商店で報酬と交換でき、イベント終了後も保持されます。

【集計と報酬】

1. 3回目の試合日22:00に戦闘が終了し、5分間の集計後に報酬受取期間に入ります。参戦したプレイヤーは同盟順位と個人順位の報酬を受け取れます。

2. イベント終了時、兵営に残っている兵士は功績に変換されます。この分の功績は実績の進捗に加算され、番付には加算されません。

3. 達成済みかつ未受取の功績実績報酬および番付報酬は、手紙で再配布されます。

四、九州制覇新規追加コンテンツ

【基本ルール】

1. 九州制覇は同盟単位のクロスサーバー対戦イベントで、各同盟は24回のポイント戦と最大4回の脱落戦を戦い、九州の覇を争います。

2. 各首長は、相手ごとに名士を配置する必要があります。同じ名士はイベント全体を通して1回しか出撃できないため、陣営をどう割り振るかが勝利の鍵です。

3. 同盟会員は各戦ごとに物資を寄付し、士気を高め、さまざまな作戦を組み合わせて戦局を変えることもできます。

【イベント参加資格】

1. イベント開始後、ただちに公示期間に入り、当日23:59までとなります。

2. 公示期間終了前15分に、同盟名簿をロックし、同盟総繁殖度を順位として、一定の同盟を選出して参加資格を付与します。

3. 注：当日23:45から23:59までは名簿集計期間です。期間中は同盟変更などの操作を行わないでください。

4. 名簿締切後は、同盟の変更、同盟への加入、役職の変更などがイベントに反映されなくなるため、早めに連絡を取り合うようにしましょう！

5. 参加資格を得ていない首長も、戦況を確認し、予想に参加して報酬を獲得できます。

【イベント日程】

イベントは順に公示期間、ポイント戦、脱落戦、報酬受取期間に分かれます。

ポイント戦：

1. ポイント戦は3日間続き、参加資格を得たすべての同盟が参加できます。

2. ポイント戦期間中、毎日14時から21時まで、毎時1回対戦が行われ、1日合計8回、累計24回です。

3. 各戦闘の結果に応じて、同盟は異なるポイントを獲得し、24回の戦闘がすべて終了した後、ポイントに基づいて順位を決定します。順位上位16の同盟はトーナメントに昇格できます。

4. ポイント戦開始時、すべての試合の対戦相手はすでに決定しています。事前に対戦状況を確認し、出陣する名士を計画できます。

トーナメント：

1. トーナメントは4日間続き、毎日20時に1回のみ対戦が行われます。参加同盟は全力で挑んでください。

2. トーナメントでは同盟ポイントは計算されず、各試合の勝利同盟は次のラウンドへ昇格し、敗北した同盟は今大会を終了します。

【戦力ルール】

1. 公示期間終了前15分に、育成戦力もロックされます。

2. ロック後は、知己、乗騎、聖獣、国策、外観、傑作などの育成システムを上昇しても、本イベントで名士の実力をさらに上昇させることはできません。

3. イベント期間中、名士の昇級、星昇級、神格、名士衣装などの育成を行うと、引き続きその名士のイベント内での実力値を上昇できます。

4. イベント期間中に獲得した新しい名士は、翌日0時に育成戦力がロックされます。

【名士配置】

1. 当日に行われる対戦にのみ配置でき、後日の試合に事前配置することはできません。

2. 各戦闘で1名の名士を出陣させることができます。同じ名士はイベント全体を通して1回しか出陣できません。

3. 本戦が始まると、出陣した名士は休息状態に入ります。実際に戦闘に登場したかどうかは関係ありません。

4. 陣営の名士は、デフォルトで配置時間の順に並び、早く配置した名士ほど先に出撃します。配置済みの名士を入れ替えても、元の出撃順は変わりません。

5. 盟主と参謀官は、各名士の出撃順を調整できます。

【戦中作戦】

1. 名士のほか、配置時に作戦も使用でき、戦局を変えることができます。

2. 作戦は4種類あり、各戦闘で使用できるのは1種類までです。慎重にお選びください。

3. 作戦「神兵降臨」を使用する際は、追加で1名の名士を奇兵として出陣させる必要があります。この名士も、今回のイベント中に再び出陣することはできません。

4. 作戦を使用するには、対応する作戦道具を消費する必要があります。同盟協力戦、イベントパックなどで作戦道具を入手できます。

5. ポイント戦では、使用した作戦は実際に発動したかにかかわらず、消費されます。トーナメントでは、作戦は実際に発動した場合のみ消費され、発動しなかった作戦は返還されます。

【同盟軍心】

1. 戦闘開始前、指定の資源を消費して三軍を報奨し、同盟の軍心値を増やせます。

2. 各対戦の軍心値はそれぞれ別に計算され、対応する試合でのみ有効になります。

3. 戦闘開始前、参戦する双方は軍心値の対戦を行い、より高い方が軍心が大いに高まり、出陣する名士全員が10%の実力バフを獲得します。

4. 双方の軍心値が同じ場合、軍心の対戦は引き分けとなり、双方とも追加の実力バフを獲得できません。

【戦闘について】

1. 双方の同盟は配置順に名士を順次送り出し、1対1の車輪戦を行います。

2. 名士の実力値は攻撃と体力に反映され、双方の名士は毎ラウンド同時に相手を攻撃し、攻撃を受けた後は相手の実力と同量の体力が減少します。

3. 体力が0まで減った名士は退場し、勝利した名士は残りの体力を継承して、相手の次の名士と戦い続けます。

4. 敵方の名士を5人連続で撃破すると、自身も退場します。残りの体力があっても同様です。

5. 一方に残りの名士がいなくなり、なお出戦できる名士がいる側の勝利となります。

6. 双方とも残りの名士がいない場合は、今回の軍心値が高い方の勝利となります。

7. 双方の軍心値が同じ場合は、同盟の総繁殖度が高い方の勝利となります。

【報酬について】

1. イベント期間中、名士を出陣させて戦闘に参加させた後は、当該戦報を視聴すると参戦報酬を1つ受け取れます。報酬は試合ごとの勝敗状況によって異なります。

2. ポイント戦終了後、同盟ポイントの順位に基づいてポイント戦番付報酬を配布します。

3. 脱落戦終了後、同盟の最終順位に基づいてトーナメント番付報酬を配布します。

4. 番付報酬は受取期間終了時点で未受取の場合、手紙で再配布されます。参戦報酬はイベント終了後に再配布されませんので、お早めにお受け取りください。

【全員予想】

1. イベントは今大会のすべての対戦記録を保存し、参加首長はいつでも自分や他の同盟のすべての戦報を確認できます。

2. 各試合ではさらに10件の厳選戦報を総合選出し、すべての首長が視聴できます。

3. ポイント戦期間中、すべての首長は参加同盟の中から、昇格すると見込む同盟を選べます。具体的な順位を予測する必要はありません。

4. トーナメント期間中、毎日その日に勝利して昇格する同盟を予想できます。

5. 対応する試合の戦闘がすべて終了した後、的中した同盟数に応じて対応する予想報酬を受け取れます。予想報酬はイベント終了後に再配布されません。

【優勝記録】

1. トーナメント最終日の20時から22時まで、優勝同盟の会員は配置選択を行えます。

2. すべての同盟会員は、未使用の位置から選択できます。早い者勝ちで、確認後は変更できません。

3. 盟主はデフォルトで中央に配置されますが、他の位置に1回だけ変更することもできます。

4. 報酬受取期間に入ると、まだ位置を選択していない会員は、同盟の役職と繁殖度に基づき、順に空き枠へ自動で補充されます。

5. 報酬受取期間中は、優勝同盟の全会員の集合写真が表示され、集合写真は過去の優勝記録にも収録され、後から確認できます。

6. 報酬受取期間中、すべての首長は今大会の優勝に1回いいねでき、いいね報酬を1つ獲得できます。

五、風華館新規追加

【会場紹介】

1. 容貌は老いても、風華は永遠に残る。旅の途中で手に入れた各種装飾は、風華館に珍蔵の証を残します。

2. 風華館は「衣装」、「キャラクター外観」、「アイコンフレーム」、「談話吹き出し」の4つの分館に分かれており、獲得した装飾は自動で対応する分館に収録されます。

3. 期間限定装飾は期限切れ後、引き続き使用できなくなりますが、すでに獲得した絵巻、共鳴進捗と風華玉は消えません。

【風華レベル】

1. 風華絵巻から「風華玉」を獲得でき、一定数の風華玉を累積すると、自動で風華レベルが上昇します。

2. 風華レベルが上昇すると、対応するレベル報酬を受け取れ、特定レベルに達すると風華バッジのデザインも昇級できます。

【風華絵巻】

1. 風華絵巻は複数のテーマに分かれており、各テーマは指定された複数の装飾で構成されます。

2. 装飾を解放または昇級すると、絵巻が自動で点灯し、一定数の風華玉を手動で受け取れます。

3. 初回を除き、同じ装飾を重複して獲得するたびに、少量の風華玉も受け取れます。同じ装飾で受け取れる総回数には上限があり、上限に達すると風華玉は付与されなくなります。

4. 同じ絵巻テーマの点灯装飾数が指定の進捗に達すると、絵巻宝箱も開けられ、追加の宝箱報酬を受け取れます。

【風華共鳴】

1. 風華共鳴も複数の組合せに分かれており、各組合せには複数の装飾が含まれます。

2. 装飾を解放または昇級すると、共鳴中の装飾レベルが自動で上昇します。

3. 同じ組合せで指定数の装飾がレベル条件を満たすと、その組合せを解放または組合せレベルを上昇でき、共鳴属性バフを獲得します。
